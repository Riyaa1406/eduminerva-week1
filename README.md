# EduMinerva: Week 1 (HTML + CSS)

A responsive landing page for **EduMinerva**, the BVCOE career guidance, tech insights and soft skills society.

## Features
- Fully responsive layout for mobile and desktop
- Sticky navbar with hover effects and smooth scrolling
- Hero section with the EduMinerva logo and gradient background
- Stats section, "What We Do" cards and past/upcoming events
- Card hover animations and smooth transitions
- Colour theme taken from the EduMinerva logo

## Tech Used
- HTML5
- CSS3 (Flexbox, Grid, media queries, transitions)

## Files
- `index.html`: page structure
- `style.css`: styling and responsiveness
- `logo.png`: EduMinerva logo

## How to Run
Download or clone the repo and open `index.html` in any browser.
